An end-to-end University AI Assistant by fine-tuning Llama-3.2-1B-Instruct using LoRA, QLoRA, and DPO for domain-specific university question answering.
Created and evaluated synthetic SFT, DPO, test, and evaluation datasets, comparing Foundation, LoRA, QLoRA, and DPO model performance.
Deployed merged fine-tuned models to Hugging Face and built a Streamlit chatbot with runtime model selection for interactive evaluation.
